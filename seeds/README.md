# Seeds del Proyecto

Esta carpeta contiene configuraciones iniciales derivadas de documentos de análisis o archivos fuente.

Archivos actuales:

- `primer-evento-inauguracion-otca.json`: configuración semilla del primer evento de prueba, sus 12 sesiones y el formulario asociado.
- `catalogos-formulario-asistencia.json`: catálogos extraídos del Excel `FormularioAsistencia.xlsx`.

Estos archivos todavía no son migraciones ejecutables. Servirán como base para crear scripts de carga inicial cuando se implemente Cloudflare D1.
